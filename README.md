# Pixel Pocket

유튜브·치지직 영상을 받고, 치지직 라이브를 녹화하는 Windows 프로그램입니다.
주소를 붙여 넣기만 하면 대기열에 담아 차례로 받아 줍니다.

## 설치

1. **[PixelPocket.zip 받기](https://github.com/anyitiating/PixelPocket_releases/releases/latest/download/PixelPocket.zip)**
2. 원하는 곳에 압축을 풉니다.
3. 폴더 안의 `PixelPocket.exe`를 실행합니다.

- 설치 과정은 없습니다. 폴더째 옮겨도 되고, 지우려면 폴더를 지우면 됩니다.
- 처음 실행할 때 SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요. (서명이 없는 프로그램이라 뜨는 경고입니다.)
- 처음 한 번은 글꼴을 준비하느라 창이 뜨기까지 몇 초 걸립니다.

## 할 수 있는 것

**유튜브**
- 영상·쇼츠·재생목록·채널·YouTube Music 다운로드
- 해상도(최대 4K), 코덱(H.264·VP9·AV1), 파일 형식(mp4·mkv·webm), HDR 우선 선택
- 오디오만 받기 (mp3·m4a·opus·flac·wav, 최대 320kbps)
- 썸네일·자막 따로 저장

**치지직**
- 다시보기 다운로드 (최대 1080p), 라이브 바로 녹화
- **자동 녹화**: [설정]에 채널을 등록하면 방송이 시작될 때 알아서 녹화합니다. 여러 채널이 동시에 방송하면 동시에 녹화합니다.

**편의 기능**
- 대기열: 여러 영상을 담아 두고 차례로 받기, 멈춘 지점부터 이어 받기
- 주소를 붙여 넣거나 브라우저에서 링크를 끌어다 놓으면 바로 담기
- 다운로드·녹화가 끝나면 Windows 알림
- 창을 닫아도 트레이(작업 표시줄 오른쪽)에서 녹화·다운로드를 계속
- Windows를 켤 때 트레이에서 자동 시작 (설정에서 끌 수 있음)
- 파일 이름 규칙 (기본: `제목_날짜`)

## 사용법

1. 위쪽 탭에서 **YOUTUBE** 또는 **CHZZK**를 고릅니다.
2. URL 칸에 영상 주소를 붙여 넣으면 정보를 가져와 대기열에 담습니다.
3. 유형·형식·해상도를 고르고 **[다운로드 시작]**을 누릅니다.
4. 받은 파일은 기본적으로 `다운로드\YouTube`, `다운로드\Chzzk` 폴더에 저장됩니다. 대기열에서 줄을 두 번 누르면 폴더가 열립니다.

저장 폴더, 파일 이름, 알림, 트레이, 자동 녹화 채널은 **[설정]**에서 바꿀 수 있습니다.

## 참고
- Windows 10·11 64비트에서 동작합니다. 영상 처리를 위한 ffmpeg가 함께 들어 있어 따로 설치할 것이 없습니다.
- 19세 이상·멤버십 전용 콘텐츠는 받지 못할 수 있습니다.
- 함께 들어 있는 ffmpeg는 GPL 라이선스입니다 (`bin\LICENSE`).
- 본인이 권리를 가졌거나 다운로드가 허용된 콘텐츠에만 사용하세요.
