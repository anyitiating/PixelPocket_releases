# Pixel Pocket

유튜브·치지직 영상을 받고 치지직 라이브를 녹화하는 Windows 프로그램입니다.

## 설치

1. **[PixelPocket.zip 받기](https://github.com/anyitiating/PixelPocket-releases/releases/latest/download/PixelPocket.zip)**
2. 압축을 풀고 `PixelPocket.exe`를 실행합니다.

처음 실행할 때 SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.

본인이 권리를 가졌거나 다운로드가 허용된 콘텐츠에만 사용하세요.
