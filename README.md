# Pixel Pocket

유튜브·치지직 영상을 받고, 치지직 라이브를 녹화하는 Windows 프로그램입니다.
이 저장소는 실행 파일 배포용입니다.

## 받기

**[최신 버전 받기](https://github.com/anyitiating/PixelPocket-releases/releases/latest)**

| 파일 | 형태 | 특징 |
|---|---|---|
| `PixelPocket.zip` | 폴더 | 압축을 풀고 안의 `PixelPocket.exe`를 실행합니다. 빨리 켜집니다. |
| `PixelPocket_Portable.exe` | 파일 하나 | 이 파일만 실행하면 됩니다. 켤 때마다 임시 폴더에 풀어서 조금 늦게 켜집니다. |

## 참고
- 서명이 없는 exe라 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다 → **추가 정보 → 실행**
- 함께 들어 있는 ffmpeg는 GPL 라이선스입니다 (`bin\LICENSE`).
- 본인이 권리를 가졌거나 다운로드가 허용된 콘텐츠에만 사용하세요.
